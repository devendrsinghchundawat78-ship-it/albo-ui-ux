# Keepsake UI

An original-branded React Native / Expo prototype of a visual save-and-organize app. This is a **UI/UX study**, not Albo code or assets. It uses original copy, generic imagery from Unsplash, and local mock data. No backend, AI extraction, social account connection, or real content imports are included.

## Run

```bash
npm install
npm run start
# press w for web, a for Android emulator, i for iOS simulator
```

## Explore

Five-tab navigation: Library, Explore, central Save, Community, Profile. Try the search, category chips, saved item details, recipe checklist and serving controls, AI-style mock chat, new collection, save-by-link preview, map place sheet, community filters, calendar, meal planner, clean-up swipe decisions, and movie picker. Interactions persist during the app session only.

The reference was an observed public 23-minute app walkthrough and current app-store screenshots. This is an interpretation of observed screens and flows, **not an exact or complete copy** of a changing proprietary UI. Media previews are bundled generic Unsplash photos downloaded for this prototype.
